# Примеры результата

`profiles.sample.jsonl`, `profiles.sample.json` и `profiles.sample.csv` содержат одну вымышленную анкету для демонстрации формата.

В JSONL каждая строка — отдельный JSON-объект. Полный текст находится в `raw_profile_text`, услуги и тарифы — в `services`, образование — в `education` и `education_entries`.
